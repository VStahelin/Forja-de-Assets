# Cleaners 2D

Estas instruções valem para os assets 2D do jogo Cleaners (Limpadores).

- Siga a direção de arte em [STYLE.md](STYLE.md) e use a paleta de [source/_theme.ts](source/_theme.ts).
- Para tarefas que envolvam o jogo, consulte a skill `.agents/skills/criar-asset/SKILL.md` e o motor de decisão em `docs/pipeline/motor-de-decisao.md` no repositório Limpadores, quando disponível. Confira o inventário em `docs/arte/progresso-assets-primeira-sala.md` antes de criar uma peça que possa já existir.
- Gere o PNG em `assets/<categoria>/` e, quando a entrega incluir o jogo, siga o guia `docs/forja/README.md` no repositório Limpadores para nomear e integrar o asset em `cleaners-godot/assets/`. Valide a importação e atualize o inventário.
